## Created with Capacitor Create App

This app was created using [`@capacitor/create-app`](https://github.com/ionic-team/create-capacitor-app),
and comes with a very minimal shell for building an app.

### Running this example

Use Node.js 22.13+ (22.x) or 24+. Build the plugin in the repository root with `npm ci && npm run build`, then run `npm ci` in this directory.

The example uses Capacitor 8. Its `xcode` dependency overrides `uuid` to the CommonJS-compatible 11.x release to address GHSA-w5hq-g745-h8pq; remove this override when Capacitor's Xcode dependency includes the fix.

To run the provided example, you can use `npm start` command.

```bash
npm start
```
